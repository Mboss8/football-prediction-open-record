# 足球赛前预测 · 公开回测数据集

一个中文足球赛前规则回测的**全量公开记录**：赛前发布即锁定，赛后自动回填，**未中的场次一条不删**。

数据源站点：**[mk.xinuu.xin](https://mk.xinuu.xin/)** · 逐场记录：[mk.xinuu.xin/evidence.html](https://mk.xinuu.xin/evidence.html)

---

## 为什么公开这个

大多数"预测"只发布命中。这不是分析，是筛选——把失败的删掉之后，命中率可以做到任意高，同时一无所知。

这份数据集的价值不在准确度，在于**它包含全部失败样本**，且每条都能追溯到一个有平台时间戳的原始消息。

## 文件说明

- `picks.csv` — 全量记录，UTF-8 带 BOM（Windows Excel 直接打开不乱码）

字段：

| 字段 | 说明 |
|---|---|
| `日期` / `联赛` / `对阵` | 比赛基本信息 |
| `推荐` | 系统给出的方向（主胜 / 客胜 / 大 2.5 / 小 2.5） |
| `信心档` | 阈值被超出的幅度分档，**不代表对比赛走势有额外信息** |
| `触发规则` | R1 / R2 / R3 / R4，规则定义见下 |
| `比分` / `判定` | 赛后结果；判定三态：命中 / 未中 / 不计入 |
| `发布时刻` | 该推荐对外发布的时刻，**早于开赛时间** |
| `结算时刻` | 结果回填的时刻 |
| `频道原始消息` | 指向该推荐原始发布消息的链接，**时间戳由平台记录，不可回溯修改** |

## 判定口径

- 按 **90 分钟（含补时）** 比分判定，**不含点球大战**。
- **未中的一律计入分母**，不做剔除、不改判、不删除。
- **走水**（未赛、腰斩、赛制异常）标为「不计入」：保留在表中并注明原因，
  但不计命中也不计未中，**不进入命中率分母**。
- 只统计**赛前公开发布过**的场次。

---

## 为什么这些数字可以被信任

不是因为本站在自称可信，而是因为**它有可核验的外部锚点**：

1. 每条记录的 `频道原始消息` 指向一条真实存在、带发布时间戳的消息；
2. 该时间戳由平台记录，本站无法追溯修改；
3. 也就是说，「赛前就锁定了这个判断」这句话可以被任何第三方核对，而不只是声明。

## 四条规则的完整定义

| 规则 | 触发条件 | 方向 |
|---|---|---|
| R1 | 主队场均积分 − 客队 ≥ 0.7 **且** 主队场均净胜球 ≥ 客队 **且** 主队场均积分 ≥ 1.2 | 主胜 |
| R2 | 客队场均积分 − 主队 ≥ 1.0 **且** 客队场均积分 ≥ 1.2 | 客胜 |
| R3 | 双方场均总进球 ≥ 3.2 | 大 2.5 |
| R4 | 双方场均总进球 ≤ 1.8 | 小 2.5 |

形态统计窗口：近 12 场、回看 150 天。选场每天运行一次，前瞻窗口 30 小时
（因此相邻两天的运行会在同一个比赛日上叠加，一天最多可能出现 6 条记录）。

已知局限：`ppg ≥ 1.2` 这条底线是**临时护栏，不是校准过的参数**，
在很小样本上挑出，有过拟合风险。

## 这个数据集不包含什么

- **不包含赔率与盘口。** 因此无法据此推导任何收益率或盈亏结论。
- 不包含伤停、首发、球员状态、教练言论、动机等信息——这些拿不到，也没有写进判断。
- 不构成任何投注建议。不提供、不引导、不链接任何博彩平台。
